# AuraMinis 1.0.0

基于已合入主线的增强功能，首次以 AuraMinis 品牌和独立包名提供 Release 构建。

## 本版内容

- 应用名称统一 AuraMinis，接入定稿折带 A 图标、自动/浅色/深色和单色主题资源。
- 新包名 `io.github.stevenking123.auraminis`；namespace 与实际类名保持 `com.openminis.app`，分别处理安装身份与组件类名。修正图标别名、无障碍、快捷方式、服务/通知/调度动作及提供器等寻址。
- 保留聊天背景、玻璃、消息底色、结构化高级记忆、模型搜索、原生公式修复，以及此前键盘与渲染优化。
- 关于页区分 Fork 与上游，保留版权及许可证归属；反馈指向本仓库，不向上游邮箱或社区误投。
- Release 不可调试，DEV_TOOLS关闭、R8开启。所有发行渠道关闭上游或未建立的自更新/自安装路径，发行兜底指向本Fork。

## 构建与验证

143项定向测试全部通过，22个测试类，非全仓或设备验收。另完成11项离线检查。已核对APK签名、Manifest、14个原生载荷、rootfs、Go与VAD混淆保留规则，服务器和下载文件SHA256一致。

源码构建输出为 unsigned，再使用维护者已长期保存、备份的稳定证书外签；交付APK已签名，不能将这两步混淆为“交付未签名包”。首次开发版本使用的同一证书不代表本包能覆盖旧包：包名不同，因此仍为独立安装。

```text
AuraMinis-1.0.0.apk
44021751 bytes
SHA256 9115e7fbc462b9e3ec0de7ff8ee7f1dcf87051f3268cf4a18bfedd08bca79e7f
```

## 安装边界

Android 8.0+、ARM64。与官方包和Minis Dev并存，不自动迁移数据，请先保留旧应用并备份。跨包恢复、当前独立包关键功能和图标切换尚待实机验收。32位PRoot辅助加载器仍为4KiB对齐，尚无16KiB页设备运行认证。

安装、迁移与构建步骤见 [正式版指南](RELEASE.md)。本版不包含此前计划稍后集中处理的其他界面细节，不宣称模型网络响应或所有机型性能得到量化提升。
