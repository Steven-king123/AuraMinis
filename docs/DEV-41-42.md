本次提交承接 Dev 40，将 Dev 41 的不可调试开发构建设置和 Dev 42 的聊天渲染优化一并保存。既有背景、高级记忆、模型选择搜索、消息底板和原生数学解析功能继续保留。

## Dev 41：隔离调试运行条件

工作区构建脚本 `scripts/configure_server_dev.py` 保持统一开发包名 `com.openminis.app.memorytest`、名称 Minis Dev，并将 Android 调试标志关闭，保留 shell profileable。DEV_TOOLS 维持 false。

Dev 41 使用与 Dev 40 相同的功能代码；用户反馈改善有限，尤其开启玻璃时键盘升降仍卡顿。因此后续没有将问题继续全部归因于 debug 构建。

脚本现在递增到 versionCode 42。仓库原始 Gradle 版本不是最终 APK 版本；服务器在独立构建工作区运行覆盖脚本。仍沿用 githubDebug 变体任务名，但最终 APK 不可调试，并不代表已启用完整 Release/R8 优化。此脚本不携带签名密钥，不自动生成随机签名；签名由私有构建环境独立完成。

## Dev 42：保留实时玻璃，减少重复工作

### 玻璃输入降采样

继续固定 Haze **1.6.10**，没有升级到 Haze 2.0 alpha。`chatGlassSurface` 显式使用 `HazeInputScale.Fixed(0.5f)`，两轴各减半。降低的是模糊输入分辨率，前景文字和图标仍保持原分辨率。

24dp 模糊半径、0.02 noise、主题 tint、边框和原有 fallback 不变。输入像素数理论约为原来的 25%，但不等于整帧耗时或显存减少 75%。玻璃细节可能发生变化，不宣称像素一致。

### 输入栏效果所有权

父 composer 保留实时玻璃；其中加号、slash 和空闲 mic 不再分别创建重复 Haze effect，而恢复普通原有底色。保留尺寸、边框、录音警示、图标、locale badge、点击和长按交互。

顶栏及独立悬浮工具状态栏继续使用独立玻璃。壁纸与消息列表继续作为两个采样源，没有删掉消息透出，没有在键盘动画中冻结玻璃，也没有延长键盘动画掩盖掉帧。

### 隔离 IME 精确高度订阅

新增 `ChatImeBottomRecovery.kt`。精确键盘高度改由稳定协程内 `snapshotFlow` 读取，不再在大 ChatScreen 组合范围中读取并以每个高度重启 effect。

仅高度属于 flow 依赖；阅读状态通过函数即时读取，near-bottom 通过 State 即时读取，回调保持更新。保留原 `userScrolledAway && isNearBottom` 条件；该观察不主动滚动、不无条件清除阅读状态。未重写反向列表布局、阅读锚点或自动滚动策略。

### 共享外观 State holder

聊天根节点持有一份外观状态，经 CompositionLocal 提供稳定 holder。子项读取同一状态，不再各自重复注册偏好监听或检查同一背景文件。独立设置及无 provider 的组件仍使用原有观察回退；文件检查保持在可取消 IO 中。背景缩放与玻璃开关仍相互独立。
