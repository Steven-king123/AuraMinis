# 高级记忆使用指南

入口：**设置 → 记忆 → 使用高级记忆**。

普通聊天可以继续使用标准记忆；高级记忆是可选功能。关闭后相关配置、记录、测试及维护入口会收起，重新开启恢复展示，不清空已有配置与记录。

## 两种记忆方式

| 方式 | 数据与用途 |
|---|---|
| 标准记忆 | 延续 OpenMinis 的 GLOBAL.md 与每日日志机制。 |
| 高级记忆 | 独立保存核心记忆和事件摘要，按相关性检索保存的记录。 |

核心记忆适合长期有效的信息，如偏好和稳定约定；事件摘要适合经历、任务进展与对话要点。高级记忆不会自动导入 GLOBAL.md、每日日志或扫描历史会话。切换模式不会把两套记录自动转换或合并。

## 配置模型

### 总结模型

用于自动整理和按对话 ID 手动生成事件摘要，需选择界面支持的 API 密钥认证模型。它不必与当前聊天模型相同。总结使用可见的用户和助手文本，不包含隐藏推理、工具输出或文件内容。

### 向量模型

用于生成查询和记忆的嵌入向量，需满足：

- API 密钥认证。
- 提供商配置支持 OpenAI 兼容 `/embeddings` 接口。
- 所选模型实际支持嵌入，而非仅支持聊天。

不支持 OAuth 认证，以及 Azure、Anthropic、Gemini 专用嵌入接口。某模型通过兼容网关接入时，应按网关实际接口能力判断，不能仅凭模型名字决定。

模型列表支持名称、ID、提供商搜索；疑似嵌入模型优先显示不代表接口已经测试成功。更换向量模型后应重建索引，不能将不同模型的向量混用。

未配置可用向量模型、请求失败或没有匹配索引时，可降级为本地关键词检索。没有合适结果不代表记忆丢失；请同时检查记录、阈值和运行状态。

## 检索与阈值测试

- **接受阈值**：0–1，越高越严格，默认 0.55。
- **最多召回数量**：限制实际接受的记录数量，默认 5，可设 1–20。
- **阈值测试**：查看候选、关键词与语义分数，以及接受或拒绝原因；不会把测试结果插入聊天。

相关性分数不是准确率或事实可信度。记录达到阈值后仍受数量等约束；没有达标记录时不会为了凑数强行召回。候选搜索和上下文注入本身还有安全上限，数量设置不是无限长度承诺。

测试时关闭“使用语义检索”仅执行本地检索；开启后会发送查询至所选向量服务，可能产生费用。候选中可以包含被拒绝的记录，因此候选总数不等于聊天中实际召回数量。修改模型、阈值或记录后请重新测试。

## 自动整理与手动摘要

自动整理与自动召回不是同一件事：前者保存摘要，后者在聊天时查找已有记忆。

自动整理默认关闭。启用需满足高级记忆开启、选择总结模型、对应会话允许使用记忆。空闲延迟默认 30 分钟，可设 1–240 分钟。

只安排启用后继续使用的符合条件的对话，不自动回溯处理历史会话。后台执行还受 Android 调度和应用运行条件影响，不应理解为精确到秒的定时任务。

需要明确处理某个已保存会话时，可在维护区输入来源对话 ID，确认后手动生成摘要。这不等于向模型开放全部历史聊天搜索。

## 管理与保护

- 支持查看、按内容或来源筛选、新增、编辑和删除记录。
- 手动新增或编辑会建立保护，避免后续自动整理覆盖该记录。
- 编辑会使原向量失效；正文仍在本机，可按需重新建立索引。
- 删除会移除正文和向量，同时保留必要来源标记，避免后台自动重新生成已删除的来源事件。
- 删除无法直接撤销。修改冲突会提示重新打开记录，不静默覆盖其他变更。

重建索引只更新向量，不修改记忆正文。取消后已完成的向量会保留，后续可再操作。

## 数据发送与费用

| 操作 | 发送至所选服务的数据 |
|---|---|
| 自动整理／手动摘要 | 符合条件的可见用户和助手文本 |
| 重建索引 | 已保存的记忆正文 |
| 语义召回／语义测试 | 查询文本 |
| 使用召回结果聊天 | 接受的记忆内容可能作为上下文发给聊天模型 |

打开设置、查看帮助、手动本地编辑本身不会请求总结或嵌入模型。模型服务可能计费，请检查提供商计费规则，并避免保存不希望后续提供给模型的敏感信息。

记忆与摘要由模型辅助，不保证提取、相关性或事实始终正确；重要信息应人工核对，也可随时编辑和删除。
